# 🏥 Satalkar Lotus Hospital Website

A responsive healthcare website developed for **Satalkar Lotus Superspeciality Hospital, Ahmednagar, Maharashtra**.

The project provides a clean and informative web interface to showcase hospital information, medical services, treatments, doctor details, and contact information.

## ✨ Features

* 🏥 Hospital overview
* 🩺 Medical services information
* 💊 Treatment information
* 👨‍⚕️ Doctor and medical team section
* 📞 Contact information
* 🏨 Healthcare and patient-care information
* 🎨 Clean and user-friendly interface
* 📱 Responsive web design

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jay3703/Satalkar_lotus_Hospital.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd Satalkar_lotus_Hospital
```

### 3. Run the website

Open `index.html` directly in your browser.

You can also use **VS Code Live Server** to run the project locally.
